# 商业换装机制库

仅在需要选择、替换或推荐视频换装方式时读取。

商业换装机制的首要目标是保持商品可信：换装要服务买家观察，不得遮掉关键版型、颜色、图案和 logo 位置太久。短视频里不要一次混用超过 2 种主机制。

## M1：点击 SKU 贴纸 + 完整模特飞入重合

适合：拼贴首帧、多个 SKU、买家互动感、短视频种草。

动作：点击目标小模特或 SKU 搭配位 -> 复制完整模特抠像作为飞入副本 -> 原位置目标贴纸立即移除并留空 -> 副本飞向中央并放大 -> 与中央模特头肩腰和姿态重合 -> 中央换成对应服装 -> 飞入副本与轮廓同时消失。

优点：能清楚说明“正在切换到哪一套商品”，与 5 套穿搭默认参数最兼容。

注意：飞入必须是完整模特副本，不是单独衣服或矩形卡片；换装后中央只保留一个模特。

## M2：布料掠过遮挡

适合：裙装、衬衫、外套、汉服、新中式、披肩或大袖。

动作：模特转身或抬手，衣摆/袖摆/裙摆短暂掠过主体区域 -> 遮挡峰值切换服装 -> 布料继续自然落下，展示新造型。

优点：利用服装自身运动完成换装，适合展示材质垂坠和面料厚薄。

注意：遮挡时间要短，不能长期遮住领口、腰线、袖口、下摆等商品关键点。

## M3：站姿转身对齐

适合：商品主图视频、通勤装、连衣裙、套装、买家决策素材。

动作：模特保持同一站位，轻微侧身、回正或 3/4 转身 -> 在身体轮廓最接近时切换服装 -> 继续同一动作展示正面或侧面。

优点：动作稳定，商品结构变化最少，适合追求真实感的电商素材。

注意：换装前后肩宽、腰线、裤长、裙长和鞋跟高度不要跳变。

## M4：衣架/商品卡滑入换装

适合：买手选品、供应商沟通、SKU 说明型视频。

动作：带有商品编号的简洁衣架或商品卡从侧边滑入 -> 与模特服装区域短暂对齐 -> 卡片滑出后模特穿上对应商品。

优点：商品与 SKU 的因果关系清楚，适合内部评审和详情页解释。

注意：商品卡不能遮住人物太久，卡上文字应少而清晰；避免生成平台无关促销语。

## M5：局部细节擦拭

适合：面料、刺绣、纽扣、口袋、领口、袖口、印花等细节卖点。

动作：镜头保持固定，手部或光标轻扫商品关键区域 -> 局部细节先匹配下一套服装 -> 全身在卡点处完成切换。

优点：能把买家的注意力带到真实卖点，适合详情页和广告二剪。

注意：只有用户提供或图片可见的细节才能写成卖点，不确定处标记需人工确认。

## M6：横向 lookbook 翻页

适合：仅首帧延展、系列上新、多套商品对比、社媒封面。

动作：画面像 lookbook 页面一样横向翻页或滑动 -> 每页保持同一模特、不同穿搭 -> 翻页完成后停在目标造型。

优点：平面商业设计感强，适合从首帧生成封面或短循环视频。

注意：翻页元素仍要保持人体轮廓和商品清晰，不要变成不可读的矩形缩略图堆叠。

## M7：步伐/手势卡点

适合：抖音、小红书、TikTok、Reels 等节奏型广告短视频。

动作：脚步落地、手掌轻拍、转身回正、抬手落下或拿包动作到达峰值 -> 服装在节拍点切换 -> 模特继续自然展示商品。

优点：节奏直接，适合移动端第一眼吸引。

注意：动作不能比商品更抢戏；每次换装后至少留出短暂展示窗口。

## M8：配饰触发

适合：包、鞋、腰带、围巾、帽子、发饰等搭配件同时销售的场景。

动作：模特轻触配饰或配饰位高亮 -> 高光沿服装边缘扩散 -> 完成整套搭配切换。

优点：适合展示完整搭配和连带购买。

注意：如果配饰不是商品或用户未提供，不要把它写成实际售卖 SKU。

## 推荐组合

- 真实商品优先：M3
- 多 SKU 互动：M1
- 裙装/汉服/新中式：M2 + M3
- 详情页卖点：M5
- 系列 lookbook：M6
- 社媒广告：M1 + M7
- 搭配件连带销售：M8 + M3

## 默认选择

- 输出模式为 `首帧 + 视频` 且穿搭套数为 5：默认 M1
- 用户强调真实上身、低干扰、商品页：默认 M3
- 用户强调国风汉服、新中式、大袖、裙摆：默认 M2
- 用户强调短视频卡点、社媒传播：默认 M7，可与 M1 组合
- 用户强调细节卖点：默认 M5
