# 商业参数推荐库

仅在用户要求“先推荐几组参数”“先给商业方案”“帮我选电商展示方向”时读取。

每组方案都应说明：目标买家、平台/用途、模特来源、穿搭风格、穿搭套数、输出模式、画幅、视频时长、首帧确认策略和推荐理由。

## 方案 1：即看即买商品还原

- 目标买家：正在比较单品真实上身效果的电商买家
- 平台/用途：淘宝、天猫、京东、独立站商品主图与详情页首屏
- 模特来源：参考模特优先；无图时原创成年商业模特
- 穿搭风格：干净基础款、真实通勤、低干扰搭配
- 穿搭套数：3-5 套
- 输出模式：仅首帧或首帧 + 视频
- 画幅：1:1 或 3:4；短视频用 9:16
- 视频时长：6-8 秒
- 首帧确认：开启
- 推荐理由：最强调商品颜色、版型、长度和细节还原，适合转化页和买家决策

## 方案 2：多 SKU 搭配对比

- 目标买家：需要横向比较多个颜色、款式或套装组合的买家
- 平台/用途：详情页组合图、买手选品提案、店铺上新页
- 模特来源：同一参考模特或同一原创模特
- 穿搭风格：同系列色彩递进、同一场景多套搭配
- 穿搭套数：5-8 套
- 输出模式：仅首帧
- 画幅：16:9、4:3 或 1:1
- 视频时长：不适用
- 首帧确认：开启
- 推荐理由：适合把 1-8 张服装图整理成统一 lookbook，让买家快速比较差异

## 方案 3：短视频种草换装

- 目标买家：被社媒内容吸引后进入商品页的潜在买家
- 平台/用途：抖音、小红书、TikTok、Reels、快手信息流
- 模特来源：参考模特可提升账号一致性；原创模特适合批量生产
- 穿搭风格：甜酷、轻熟、通勤、度假、街拍等强场景风格
- 穿搭套数：5 套
- 输出模式：首帧 + 视频
- 画幅：9:16
- 视频时长：8-12 秒
- 首帧确认：开启
- 推荐理由：保留原 Skill 的卡点换装优势，同时加入商品卖点和买家观察点

## 方案 4：国风汉服与节日上新

- 目标买家：关注面料层次、形制氛围和节日穿搭的服装买家
- 平台/用途：国风汉服店铺上新、节日专题页、直播间预热视频
- 模特来源：参考模特或原创成年东方气质模特
- 穿搭风格：国风汉服、马面裙、新中式、节日礼服
- 穿搭套数：4-6 套
- 输出模式：首帧 + 视频
- 画幅：9:16 或 3:4
- 视频时长：8-10 秒
- 首帧确认：开启
- 推荐理由：适合展示大袖、裙摆、刺绣、披帛和层次，但要避免把概念美术当成真实商品细节

## 方案 5：跨境轻量广告素材

- 目标买家：移动端快速浏览的跨境电商消费者
- 平台/用途：Amazon、Shopee、Lazada、TikTok Shop、独立站广告
- 模特来源：原创成年商业模特，按市场选择自然肤色和气质
- 穿搭风格：清晰、明亮、国际化、低背景干扰
- 穿搭套数：3-5 套
- 输出模式：首帧 + 视频
- 画幅：9:16、1:1 或 16:9
- 视频时长：6-9 秒
- 首帧确认：开启
- 推荐理由：强调第一眼识别商品、适配广告裁剪和多市场复用

## 方案 6：买手选品复盘

- 目标买家：服装买手、选品团队、品牌运营
- 平台/用途：内部评审、供应商沟通、上新组合决策
- 模特来源：原创标准模特或指定参考模特
- 穿搭风格：按价格带、场景、季节或系列主题分组
- 穿搭套数：5-8 套
- 输出模式：仅首帧
- 画幅：16:9 或 4:3
- 视频时长：不适用
- 首帧确认：开启
- 推荐理由：输出重点不是传播感，而是让团队快速判断款式组合、颜色体系和搭配风险

## 快速选择规则

- 用户要“真实商品上身”：优先方案 1
- 用户有多张服装图并要比较：优先方案 2
- 用户要短视频传播：优先方案 3
- 用户写了国风、汉服、新中式：优先方案 4
- 用户要跨境广告：优先方案 5
- 用户是买手或内部选品：优先方案 6
