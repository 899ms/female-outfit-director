# 电商服装换装导演

`ecommerce-fashion-tryon-director` 是一个面向 Codex / Skills 兼容智能体的中文商业工作流 Skill，用来把电商服装买家、买手或店铺运营输入的模特、服装图和参数，整理成可复用的模特换装首帧、商品搭配方案与短视频提示词。

它适合商品主图、详情页、lookbook、短视频广告、买手选品和供应商沟通等场景。Skill 会优先保证商品版型、颜色、图案、材质类别和 SKU 映射可信，避免把创意效果凌驾于商业真实之上。

## 主要能力

- 支持 `参考模特` 和 `原创模特` 两种模式；参考模特模式下会要求模特参考图。
- 支持最多 8 张服装图，并按服装图/SKU 编号生成多套搭配。
- 支持穿搭风格、穿搭套数、输出模式、画幅、视频时长和视频前确认首帧等参数。
- 生成电商首帧图片提示词、商品与搭配映射、商业质检清单和负面提示词。
- 在需要视频时输出逐段换装时间轴和精简视频提示词。
- 内置商业换装机制，覆盖点击 SKU 贴纸、布料遮挡、站姿转身、商品卡滑入、细节擦拭、lookbook 翻页和社媒卡点。
- 强制保留商品核心细节，不夸大材质、功能、显瘦、增高或授权信息。

## 参数面板

该 Skill 对齐如下电商换装参数：

| 参数 | 默认或规则 |
| --- | --- |
| 模特 | `参考模特` 或 `原创模特` |
| 模特参考图 | 参考模特模式必填 |
| 服装图 | 可选，最多 8 张；有图时优先商品保真 |
| 穿搭风格 | 自由输入，例如国风汉服、都市通勤、甜酷街拍 |
| 穿搭套数 | 默认 5 套，可按需求输出 1-8 套 |
| 输出 | `首帧 + 视频` 或 `仅首帧` |
| 画幅 | `16:9`、`9:16`、`1:1`、`4:3`、`3:4`，默认 `9:16` |
| 时长 | 默认 8 秒，仅视频模式使用 |
| 生成视频前确认首帧 | 默认开启，先确认首帧再进入视频脚本 |

## 当前默认规则

- 模特：无参考图时使用原创成年商业模特。
- 服装：有服装图时按图还原；无服装图时生成概念搭配并显式标记。
- 套数：5 套。
- 输出：首帧 + 视频。
- 画幅：9:16。
- 时长：8 秒。
- 首帧确认：开启。
- 背景：干净浅灰白电商影棚。
- 镜头：固定机位，商品细节清晰。
- 声音：默认无背景音乐，仅保留轻点击、布料掠过和卡点提示音。

用户明确给出的参数始终优先于默认值。

## 商业真实原则

电商素材必须能帮助买家判断，而不是误导买家：

- 不改变商品核心版型、颜色、图案、领口、袖型、下摆、口袋、扣件、拉链和 logo 位置。
- 不凭空添加品牌、联名、授权、功能面料、价格或平台标识。
- 不把普通材质夸写成真丝、羊绒、防水、抗皱、速干等卖点。
- 不夸大显瘦、增高、塑形或医美效果。
- 不确定的参考图细节要列入 `需人工确认`。
- 模特必须为成年人。

## 快速安装

完整步骤见 [安装与更新指南](docs/INSTALLATION.md)。

```bash
git clone https://github.com/liyue-aigc/female-outfit-director.git
mkdir -p ~/.codex/skills/ecommerce-fashion-tryon-director
cp -R female-outfit-director/skill/. ~/.codex/skills/ecommerce-fashion-tryon-director/
```

安装后重新打开 Codex 任务，并使用：

```text
$ecommerce-fashion-tryon-director
模特：参考模特；服装图：5 张；穿搭风格：国风汉服；穿搭套数：5；输出：首帧 + 视频；画幅：9:16；时长：8 秒；生成视频前确认首帧。
请先生成电商首帧提示词、商品与搭配映射和质检清单。
```

第一次使用建议阅读 [首次使用教程](docs/FIRST_USE.md)。
