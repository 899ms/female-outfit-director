# 首次使用教程

## 1. 最简单的调用方式

在请求开头写出 Skill 名称，然后把界面参数写成自然语言：

```text
$ecommerce-fashion-tryon-director
模特：原创模特；服装图：可选；穿搭风格：都市通勤；穿搭套数：5；输出：首帧 + 视频；画幅：9:16；时长：8 秒；生成视频前确认首帧。
请先生成电商首帧提示词、商品与搭配映射、商业质检清单和负面提示词。
```

未提供模特图时，Skill 会使用原创成年商业模特。未提供服装图时，服装会被标记为概念搭配，不会声明为真实商品还原。

## 2. 使用参考模特

上传一张清晰模特参考图，并输入：

```text
$ecommerce-fashion-tryon-director
模特：参考模特；已上传模特参考图；穿搭风格：轻熟通勤；穿搭套数：5；输出：仅首帧；画幅：3:4。
请保持同一张脸、同一发型、同一身材比例和同一成年年龄感。
```

选择参考模特时，模特参考图是必填项。如果没有图，Skill 会要求补充模特图或改用原创模特。

## 3. 使用服装图/SKU

上传 1-8 张服装图后，可以这样写：

```text
$ecommerce-fashion-tryon-director
模特：参考模特；已上传模特参考图；服装图：5 张；穿搭风格：国风汉服；穿搭套数：5；输出：首帧 + 视频；画幅：9:16；时长：8 秒。
每套造型都要绑定对应服装图编号，优先还原颜色、领口、袖型、裙摆、刺绣和配饰位置。
```

Skill 会用服装图 1、服装图 2 等稳定编号建立商品与搭配映射。如果图片里看不清材质、图案或 logo，会列入 `需人工确认`。

## 4. 先要方案，再生成提示词

如果还没决定商业方向，可以先让 Skill 推荐：

```text
$ecommerce-fashion-tryon-director
我有一批女装上新图，先推荐 6 组适合电商买家复用的参数方案，暂时不要生成完整提示词。
```

选定方案后继续说：

```text
选择方案 3，按 9:16、8 秒、首帧 + 视频生成完整素材方案，视频前先确认首帧。
```

## 5. 视频前确认首帧

默认开启“生成视频前确认首帧”。开启时第一轮只输出：

1. 参数锁定结果
2. 商品与搭配映射
3. 首帧图片提示词
4. 首帧商业质检清单
5. 负面提示词 / 强制约束

确认首帧方向后，再继续输入：

```text
首帧方向确认，继续生成 8 秒视频时间轴和精简视频提示词。
```

这样可以先检查商品颜色、版型、图案、logo 和搭配关系，减少视频阶段返工。

## 6. 指定画幅和输出模式

可用画幅：

- `16:9`：横版 lookbook、买手提案、内部评审
- `9:16`：抖音、小红书、TikTok、Reels、直播预热视频
- `1:1`：平台主图、广告方图
- `4:3`：详情页模块、商品组合图
- `3:4`：竖版商品图、模特主图

输出模式：

- `仅首帧`：适合商品主图、详情页、lookbook、选品对比
- `首帧 + 视频`：适合广告短视频、种草内容、直播间预热视频

## 7. 指定换装方式

可以直接指定机制，例如：

```text
$ecommerce-fashion-tryon-director
使用 M1 点击 SKU 贴纸换装：点击后复制完整模特贴纸飞入中央，原位置贴纸立即消失，重合后中央切换成对应服装。
```

也可以让 Skill 推荐：

```text
这批服装是新中式裙装，希望商品真实、动作优雅，请推荐 3 种适合 8 秒视频的换装方式。
```

## 8. 提高商业可用性的写法

- 明确平台和用途，例如主图、详情页、广告、lookbook、买手提案。
- 服装图尽量清晰，包含正面、侧面或细节图。
- 对每件商品写清款号、颜色、面料类别、尺码段、价格带或重点卖点。
- 商品真实优先时，写明“不要改变版型、颜色、图案和 logo 位置”。
- 需要视频时，先确认首帧，再生成时间轴。
- 不确定的商品细节不要让模型编造，要求列入 `需人工确认`。

## 9. 可直接复制的首次请求

```text
$ecommerce-fashion-tryon-director
模特：参考模特；已上传模特参考图；服装图：5 张；穿搭风格：国风汉服；穿搭套数：5；输出：首帧 + 视频；画幅：9:16；时长：8 秒；生成视频前确认首帧。

请把 5 张服装图分别作为服装图 1-5 建立商品与搭配映射，保持同一位成年模特、同一张脸、同一发型、同一身材比例。首帧用于电商商品展示和短视频封面，必须优先还原服装颜色、领口、袖型、裙摆、刺绣、配饰和面料垂坠，不添加无关品牌、水印或促销大字。

本轮先输出参数锁定结果、商品与搭配映射、首帧图片提示词、首帧商业质检清单和负面提示词；确认首帧后再生成视频时间轴。
```
